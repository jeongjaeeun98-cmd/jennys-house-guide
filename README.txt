제니네 집 모바일 안내 웹페이지

GitHub 업로드 방법
1. 이 압축파일을 풉니다.
2. 저장소의 기존 index.html 및 index.html.html 파일을 삭제합니다.
3. 이 폴더 안의 index.html, README.txt, .nojekyll 파일을 저장소 최상단(root)에 업로드합니다.
4. GitHub Settings > Pages에서 main / (root)를 선택합니다.

참고
- index.html 한 파일 안에 화면 디자인, 기능, 이미지가 모두 포함되어 있습니다.
- assets 폴더는 필요하지 않습니다.
